## Method

- **Cold build** is a fresh process each sample: read the tree off disk, construct the engine, produce the stylesheet. The figure is the fastest of 3 runs, because noise on a cold start only ever adds.
- **Rebuild** figures are medians from [tinybench](https://github.com/tinylibs/tinybench) against an already-warm engine, the state a dev server is in when you save a file. The incremental case changes one file's classes on every iteration, so no iteration but the first can be served from a candidate cache.
- **Scan only** is each engine's own public extraction path with no CSS generated.
- **Output** is minified by the same LightningCSS pass for all three, targeting one modern browser baseline, so the byte counts are comparable.
- **Peak RSS** is `process.resourceUsage().maxRSS` for the cold-build process.
